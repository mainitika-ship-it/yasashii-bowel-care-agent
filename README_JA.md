# やさしい排便モニター — 実行ガイド

介護者の「観察・記録・申し送り」を助ける試作です。診断機器ではありません。
正式な英語の説明は [README](README.md) を参照してください。

## まず無料で動かす

このリポジトリをダウンロードし、READMEが入ったフォルダで実行します。Python 3.10以上が必要です。
MacやLinuxで `python` が見つからなければ、`python3` に置き換えてください。

```bash
python src/demo.py --mode offline
```

AWSへの接続・認証情報・追加ライブラリのインストールは不要です。安全な模擬データだけで、次の一連動作を試します。

| 表示 | 意味 | 残すもの |
|---|---|---|
| PASS | 観察を記録 | 観察記録1件 |
| HOLD | 人の確認待ち | 確認待ち1件。事実として確定しない |
| STOP | 安全のため停止 | 安全停止1件。観察記録には加えない |

実行後に表示される `view_path` の `report.html` をブラウザで開くと、結果が日英併記で見られます。
申し送りの観察件数は **1件** です。確認待ちと安全停止を足して3件にはしません。
毎回別の実行フォルダを作るため、前回の結果と混ざりません。

**「無料の模擬実行」はAWS接続の成功証拠ではありません。** 画面にも明記します。
画面は閲覧専用で、介護者の承認ボタンはまだありません。本人やご家族の画像・実際の介護記録は使わないでください。
